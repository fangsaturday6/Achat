# 计划 3：群的网页界面

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 照 `docs/decisions.md` 8n 和画布“群：几个人的 AI 一起开会”一节，把群做到网页上：消息列表里的群、群聊、@ 选择列表、底部的次数和叫停 / 继续、群设置、发起群聊和邀请、进群卡片；顺带补上路线总览里网页要用到的几处服务端遗留。

**Architecture:** 服务端只补网页缺的东西：`GroupSummary` 加 `lastSender`、`faces`，群里有新消息时更新 `updatedAt`，被邀请的人能下载开场白的附件，报错不带 id，解散作废邀请，一次回答也算答过更早没等到的 @。网页分两层：新文件 `web/groups.js` 放群界面的纯函数（不碰页面，node 测试直接引入，文案和 `src/types.ts` 用测试对齐），`web/text.js` 放网页共用的文字函数（从 `app.js` 搬出来）；`web/app.js` 里一块界面一个函数，只管画和调用 `/api/groups/*`。群事件已经和私聊走同一条 `/api/events`（`src/relay/threads-api.ts`），网页照旧收到就刷新；群聊的输入框跨刷新保留，菜单或正在改的输入框开着时刷新往后推。

**Tech Stack:** TypeScript（Node 22，`node:test` + tsx），SQLite（`node:sqlite`），原生 JS 网页（`web/app.js`，ES 模块），MCP SDK。

**部署：** 服务端和网页都由云端提供，照平常跑一次 `bash deploy/upload.sh`（会签名发布；电脑上的 Achat 自动更新时也会拿到新的 `web/`，但本机模式不显示群）。浏览器里没刷新的旧页面收到新字段不受影响。

## 和 8n、设计稿不一样的地方（写计划时定下的，Task 10 记进 `docs/decisions.md`）

1. **网页上开场白在哪写**：设计稿只画到“完成”。这里点“完成”先进一个空的群聊（`#/new-group`），输入框预填“@所有人 ”，第一句话发出去才建群：它就是开场白，群名取第一句（服务端已有的 `nameFrom`）。和私聊“话题取第一句”一样，不加群名输入框；被邀请的人的卡片上也总有一句话。
2. **消息列表的“+”变成菜单**（发起群聊、添加朋友），是 8n 定的；通讯录的“+”照旧直接添加朋友，免得改动已有的加朋友路径。
3. **系统消息不带视角**：照 8n“写计划时定下的细节”，写“老方叫停了群里沟通”，设计稿画的是“你叫停了群里沟通”。
4. **灰字行**：同一种状态合在一起（“老王的 Claude、小林的 Claude 无需回复”），超过 2 个写“老王的 Claude 等 5 个 AI 无需回复”；叫停期间发的消息也写名字（“老王的 Codex 已叫停”），设计稿那一条只写了“已叫停”。只有一个 AI 又没有原因时，这行字不能点。
5. **@ 怎么存**：消息里存不带视角的名字（“@老方的 Claude”），和后台 AI 写的一样；每个人看到的是自己的视角（老方看到“@我的 Claude”），这正是设计稿画的效果。
6. **群设置里设计稿没画的操作**：点成员格子弹菜单，自己的 AI 是“退出群聊”，群主点别人的 AI 是“移出群聊”；底部“退出群”是让自己在群里的 AI 全部退出。群名在那一行里直接改，Return 保存、Esc 取消。
7. **底部次数**：自己有好几个 AI 在群里时，写最快用完的那个；用完了变成 `--danger` 色。
8. **群聊气泡上方不写模型**（设计稿没写；私聊照 8m 照写）。
9. **四宫格一人一格优先**：设计稿“被邀请”那屏的四宫格里同一个人出现了两次；这里先每人一格，不够 4 格再补同一个人的别的 AI。
10. **深色**：Achat 现在没有深色主题。“深色”这一项只检查系统切到深色后页面照常可读、控件没有变黑；这份计划不加深色主题。
11. **窄屏**：8n 说第一版不做窄屏的群界面。这里只保证能用：照现有的单栏切换；群设置铺满内容区；@ 列表和灰字浮层左右各留 12px；发起群聊弹窗铺满宽度，“已选”一栏收起，个数写在按钮左边。
12. **改群名、移出、解散不加 AI 工具**：8n 的前台 AI 工具里没有它们，移出和解散影响别人的 AI，先留给人在网页上做；接口都有（`/rename`、`/remove`、`/dissolve`）。
13. **刷新不打断人**：事件来时如果菜单、灰字浮层开着，或者正在改群名、次数，就等关掉再刷新；群聊的输入框跨刷新保留（打到一半的字、选好的文件、光标都在）。这顺带让私聊里的菜单也不会再被事件关掉。
14. **报错说人话**：服务端几处报错去掉 id；网页连不上服务时写“连不上 Achat，检查网络后再试”，服务端没给出错原因时写“Achat 出错了，过一会儿再试”，不显示浏览器的英文原始报错。

| 问题 | 怎么处理 |
|---|---|
| 有几处报错带 id，网页做出来前要改成人话 | Task 2：`找不到这个 AI：<id>`、`只能 @ 群里的 AI：<id>`、`只能让自己的 AI 进群：<id>` 改成写名字或不写；Task 4：网页的 `api()` 不再显示 `HTTP 502`、`Failed to fetch` |
| 被邀请的人看得到开场白带的附件却下载不了 | Task 1：给看。开场白就是邀请要讨论的事，看得见附件却打不开最糟；只放行开场白那一条的附件，只在邀请还开着时，别的消息的附件仍然只给成员 |
| 解散不作废还开着的邀请；解散后再退群或移出，还会往只读的群里写系统消息 | Task 2：网页上会直接露出来（死掉的“加入”按钮、只读群里冒出新消息）。解散时作废邀请并通知被邀请的人；解散后退群不写系统消息（退群是把死群从列表里拿掉），移出直接拒绝 |

```ts
  private summary(caller: Caller, g: Group, invite: InviteRow | null): GroupSummary {
    const viewer = caller.account;
    const last = invite ? null : (this.store.messages(g.id, 0, 1)[0] ?? null);
    return {
      ...g,
      role: invite ? "invited" : "member",
      memberCount: this.store.members(g.id).length,
      lastMessage: last,
      lastSender: last?.sender ? this.nameFor(last.sender, viewer) : null,
      faces: this.faces(g.id, viewer),
      unread: invite ? true : this.unread(caller, g.id),
      myInvite: invite ? this.inviteView(invite, viewer) : null,
    };
  }

  // The 四宫格: one AI per person first, in the order they joined, then the
  // rest, four at most.
  private faces(groupId: string, viewer: string): string[] {
    const rows = this.store.members(groupId);
    const first = rows.filter((m, i) => rows.findIndex((x) => x.owner === m.owner) === i);
    return [...first, ...rows.filter((m) => !first.includes(m))].slice(0, 4).map((m) => this.nameFor(m.agent, viewer));
  }
```

把 `readable(...)` 换成：

```ts
  // Whether an account may read a group's files: a member all of them; someone
  // invited, while the invite is open, those of the opening message, which
  // the invite card shows.
  readable(account: string, groupId: string, messageId?: number): boolean {
    const group = this.store.group(groupId);
    if (!group) return false;
    if (this.store.members(groupId).some((m) => m.owner === account)) return true;
    if (messageId === undefined || !group.openerSeq) return false;
    const invited = this.store.invitesFor(account, this.stamp()).some((i) => i.groupId === groupId);
    return invited && this.store.message(groupId, group.openerSeq)?.id === messageId;
  }
```

```js
// Pictures shown in a conversation; other files are cards to download.
export const SHOWN_TYPES = new Set(["image/png", "image/jpeg", "image/gif", "image/webp"]);

// Joins text with a space only where a Latin word meets a Chinese one:
// "连接 Claude Code"、"连接豆包".
export function cjk(...parts) {
  const han = /[一-鿿]/;
  return parts.reduce((out, part) => {
    const a = out.at(-1) ?? "";
    const b = part[0] ?? "";
    const gap = (/[A-Za-z0-9]/.test(a) && han.test(b)) || (han.test(a) && /[A-Za-z0-9]/.test(b));
    return gap ? `${out} ${part}` : out + part;
  });
}

// The words of a message in a list: what it said, or what it sent.
export function messageText(m) {
  if (m.body || !m.files?.length) return m.body;
  return m.files.every((f) => SHOWN_TYPES.has(f.type)) ? "[图片]" : `[文件] ${m.files.find((f) => !SHOWN_TYPES.has(f.type)).name}`;
```

```js
function renderPeople(r) {
  const entries = [];
  for (const p of people()) {
    const threads = p.threads.filter((t) => matches(p.name, t.topic, agentName(t.from), agentName(t.to)));
    if (!threads.length) continue;

        open ? null : h("span", { class: "item-sub" }, preview(latest)),

    );

        return renderListBody(r);
      }
      state.expanded.add(p.key);

          : h("span", { class: "convo-status" }, t.status === "pending" ? "等待批准" : t.status === "active" ? "进行中" : shortTime(t.updatedAt));
      rows.push(
        h(
          "a",
          { class: "convo", href: `#/t/${t.id}`, "aria-current": r.id === t.id ? "true" : null },
```

```js
// A name as written in the group, from nobody's side, as the AIs read and
// write it ("@老方的 Claude"); the page names the person's own "我的 Claude".
export function plainName(name, myName) {
  if (name === "我") return myName;
  return name.startsWith("我的") ? `${myName}的${name.slice(2)}` : name;
}

// The @s a message makes, as written in it and as this person reads them,
// longest first. `me`: the person's name and seat (an AI may @ its person).
export function tagsOf(mentions, names, me) {
  const tags = [];
  for (const id of mentions) {
    if (id === ALL) tags.push({ find: "@所有人", show: "@所有人" });
    else if (id === me.seat) tags.push({ find: `@${me.name}`, show: `@${me.name}` });
    else if (names[id]) {
      const plain = plainName(names[id], me.name);
      tags.push({ find: `@${plain}`, show: `@${names[id]}` });
      // The person's own front AI may have written it from their side.
      if (plain !== names[id]) tags.push({ find: `@${names[id]}`, show: `@${names[id]}` });
    }
  }
  return tags.sort((a, b) => b.find.length - a.find.length);
}

// A message's words cut into plain text and @s; where two @s start at the
// same place, the longer one is taken.
export function segments(body, tags) {
  const out = [];
  let i = 0;
  while (i < body.length) {
    let hit = null;
    for (const t of tags) {
      const at = body.indexOf(t.find, i);
      if (at >= 0 && (!hit || at < hit.at || (at === hit.at && t.find.length > hit.t.find.length))) hit = { at, t };
    }
    if (!hit) {
      out.push({ text: body.slice(i), at: false });
      break;
    }
    if (hit.at > i) out.push({ text: body.slice(i, hit.at), at: false });
    out.push({ text: hit.t.show, at: true });
    i = hit.at + hit.t.find.length;
  }
  return out;
}

// Where a time goes between messages: before the first, and after a quiet
// five minutes or more. Returns the seqs it goes before.
export function timeBreaks(messages, gapMs = 5 * 60_000) {
  const out = new Set();
  let last = null;
  for (const m of messages) {
    const at = Date.parse(m.createdAt);
    if (last === null || at - last >= gapMs) out.add(m.seq);
    last = at;
  }
  return out;
}

// The gray line under a message: the AIs it called on that did not reply,
// those in the same state together; null once every one replied. `open`: a
// click has more to show, for more than one AI or a reason.
export function receiptLine(receipts, names) {
  const items = receipts
    .filter((r) => r.state !== "replied")
    .map((r) => ({ agent: r.agent, name: names[r.agent] ?? "已移除的 AI", state: r.state, reason: r.reason }));
  if (!items.length) return null;
  const byState = new Map();
  for (const i of items) byState.set(i.state, [...(byState.get(i.state) ?? []), i.name]);
  const text = [...byState]
    .map(([state, who]) => {
      const named = who.length > 2 ? cjk(who[0], `等 ${who.length} 个 AI`) : who.join("、");
      return `${named} ${state === "reading" ? "正在看…" : RECEIPT_LABELS[state]}`;
    })
    .join(" · ");
  return { text, reading: byState.has("reading"), open: items.length > 1 || items.some((i) => i.reason), items };
}
```

```js
// the AIs that are on (others' before the person's own), then those whose
// computer is off, and last, grayed out, those that cannot answer yet.
// `query`: what was typed after the @.
export function pickerOptions(members, query = "") {
  const q = query.toLowerCase();
  const fits = (name) => !q || name.toLowerCase().includes(q);
  const rank = (m) => (!m.canReceive ? 3 : !m.online ? 2 : m.quota !== undefined ? 1 : 0);
  const ais = members
    .map((m, i) => ({ m, i }))
    .filter(({ m }) => fits(m.name))
    .sort((a, b) => rank(a.m) - rank(b.m) || a.i - b.i)
    .map(({ m }) => ({ id: m.agent, name: m.name, note: !m.canReceive ? "还不能接收" : !m.online ? "不在线" : null, disabled: !m.canReceive }));
  const everyone = fits("所有人") || "all".startsWith(q) ? [{ id: ALL, name: "所有人", note: null, disabled: false }] : [];
  return [...everyone, ...ais];
}

// The @ being typed just before the caret, and what follows it; null when
// there is none, or the line or a space after a name ended it.
export function mentionAt(text, caret) {
  const before = text.slice(0, caret);
  const at = before.lastIndexOf("@");
  if (at < 0) return null;
  const query = before.slice(at + 1);
  return /\n|\s$/.test(query) || query.length > 30 ? null : { start: at, query };
}

// What the person wrote, as it goes into the group: the AIs it @s (所有人
// first, then in the order written), and each "@我的 Claude" written from
// nobody's side ("@老方的 Claude"), as the AIs write. Longer names first, so
// "@老王的 Codex（iMac）" is not also taken for "@老王的 Codex".
export function composeMessage(text, members, myName) {
  let marked = text.trim();
  for (const m of [...members].sort((a, b) => b.name.length - a.name.length)) {
    marked = marked.replaceAll(`@${m.name}`, `@\u0000${m.agent}\u0000`);
  }
  const mentions = marked.includes("@所有人") ? [ALL] : [];
  const body = marked.replace(/@\u0000([^\u0000]*)\u0000/g, (_, id) => {
    if (!mentions.includes(id)) mentions.push(id);
    return `@${plainName(members.find((m) => m.agent === id).name, myName)}`;
  });
  return { body, mentions };
}

// The person's AI nearest its 每天次数, for the bottom of the group: "我的
// Claude 今天 12 / 30 次". `full` once it is used up. Null without one.
export function quotaLine(members) {
  const mine = members.filter((m) => m.quota !== undefined);
  if (!mine.length) return null;
  const m = mine.reduce((a, b) => (b.usedToday / b.quota > a.usedToday / a.quota ? b : a));
  return { agent: m.agent, text: `${m.name} 今天 ${m.usedToday} / ${m.quota} 次`, full: m.usedToday >= m.quota };
}
```

```js
// ↑↓ move, Return or Tab picks, Esc closes; a pick writes "@名字 ".
function mentionPicker(box, groupOf) {
  const el = h("div", { class: "menu mention-picker", role: "listbox", id: "mention-picker", "aria-label": "选择要 @ 的 AI", hidden: true });
  let at = null;
  let options = [];
  let active = 0;
  const close = () => {
    at = null;
    el.hidden = true;
    box.removeAttribute("aria-activedescendant");
  };
  const pick = (o) => {
    if (!at || !o || o.disabled) return;
    box.setRangeText(`@${o.name} `, at.start, box.selectionStart, "end");
    close();
    box.focus();
  };
  const paint = () => {
    el.replaceChildren(
      ...options.map((o, i) => {
        const row = h(
          "div",
          { class: `mention-option${i === active ? " on" : ""}`, role: "option", id: `mention-${i}`, "data-agent": o.id, "aria-selected": String(i === active), "aria-disabled": o.disabled ? "true" : null },
          o.id === ALL ? groupAvatar(facesOf(groupOf()), 28) : avatar(o.name, 28),
          h("span", { class: "grow" }, o.name),
          o.note ? h("span", { class: "muted" }, o.note) : null,
        );
        // mousedown, so the box keeps its focus and caret.
        row.addEventListener("mousedown", (e) => {
          e.preventDefault();
          pick(o);
        });
        return row;
      }),
    );
    box.setAttribute("aria-activedescendant", `mention-${active}`);
  };
  const refresh = () => {
    at = mentionAt(box.value, box.selectionStart);
    options = at ? pickerOptions(groupOf().members, at.query) : [];
    if (!options.length) return close();
    active = Math.min(active, options.length - 1);
    el.hidden = false;
    paint();
  };
  box.addEventListener("input", () => {
    active = 0;
    refresh();
  });
  // Ahead of writeBox's own Return, which would send.
  box.addEventListener(
    "keydown",
    (e) => {
      if (el.hidden || e.isComposing) return;
      if (e.key === "ArrowDown" || e.key === "ArrowUp") {
        e.preventDefault();
        const step = e.key === "ArrowDown" ? 1 : -1;
        for (let i = 1; i <= options.length; i++) {
          const next = (active + step * i + options.length) % options.length;
          if (!options[next].disabled) {
            active = next;
            break;
          }
        }
        paint();
      } else if (e.key === "Enter" || e.key === "Tab") {
        e.preventDefault();
        e.stopImmediatePropagation();
        pick(options[active]);
      } else if (e.key === "Escape") {
        e.preventDefault();
        close();
      }
    },
    { capture: true },
  );
  // A redraw takes the box off the page for a moment; it closes only when the focus really left.
  box.addEventListener("blur", () => setTimeout(() => document.activeElement !== box && close(), 100));
  return { el, refresh: () => !el.hidden && refresh() };
}
```

```js
// The members in 群设置: the AIs in the group (the person's own marked
// `mine`), then those invited, who show as 等加入. `id`: the AI, or the invite.
export function settingsTiles(g) {
  return [
    ...g.members.map((m) => ({ id: m.agent, name: m.name, waiting: false, mine: m.quota !== undefined })),
    ...g.invites.map((i) => ({ id: i.id, name: i.agentName ?? i.name, waiting: true, mine: false })),
  ];
}

// What a click on a member in 群设置 offers: the person's own AI may leave;
// 群主 may remove another's. Nothing once dissolved, nor for those invited.
export function tileActions(tile, g, me) {
  if (tile.waiting || g.status === "dissolved") return [];
  if (tile.mine) return ["leave"];
  return g.owner === me ? ["remove"] : [];
}

// 每天次数 as typed, or null when it is not a whole number from 1 to the most.
export function quotaOf(text) {
  const n = Number(String(text).trim());
  return String(text).trim() !== "" && Number.isInteger(n) && n >= 1 && n <= QUOTA.max ? n : null;
}
```

```js
// What is picked in 发起群聊 and 邀请: people ({person, name}), who choose
// their AIs, and AIs ({agent, owner, name}). Picking a person drops their
// AIs picked one by one, and the other way round; picking again unpicks.
export function togglePick(picked, item) {
  const key = (p) => p.agent ?? `person:${p.person}`;
  if (picked.some((p) => key(p) === key(item))) return picked.filter((p) => key(p) !== key(item));
  const clash = item.person ? (p) => p.owner === item.person : (p) => p.person === item.owner;
  return [...picked.filter((p) => !clash(p)), item];
}

// What 完成 sends, as /api/groups takes members: {"agent"} or {"account"}.
export function targetsOf(picked) {
  return picked.map((p) => (p.person ? { account: p.person } : { agent: p.agent }));
}
```

```js
// those that can answer ticked; just the one asked for by name, ticked and
// fixed. 豆包 and the like can join but only speak when told.
export function inviteChoices(invite, agents) {
  const mine = agents.filter((a) => a.client !== "person");
  const shown = invite.agent ? mine.filter((a) => a.id === invite.agent) : mine;
  return shown.map((a) => ({
    id: a.id,
    name: a.name,
    client: a.client,
    checked: !!invite.agent || a.canReceive !== false,
    locked: !!invite.agent,
    speaksOnly: a.canReceive === false,

}
```
