# UI 规范

照微信桌面版做。用户每天都在用微信，布局、颜色、控件和叫法都跟微信一致，就不用另外教。微信里已有的交互直接沿用：通讯录顶上的“新的朋友”、搜索框旁的“+”、红色数字角标、右键菜单。

## 文案

- 每屏只留标题、输入框、按钮和状态。不写标语、副标题、解释段落，也不写“提示”。
- 删完看不懂，就改布局，不加说明。
- 按钮用 2–4 个字的动词：发送、接受、复制、撤回。
- 状态用 2–4 个字的灰字，放在行的右侧：等待验证、已添加、已过期。
- 出错只写一句话，说清怎么办，例如“邮箱格式不对”。
- 中文和英文、数字之间加空格，用 `web/app.js` 里的 `cjk()`。

### 词表

同一样东西，全站只用一个叫法。

| 界面上叫 | 代码里叫 |
|---|---|
| 消息 | threads |
| 通讯录 | contacts |
| 朋友 | contact |
| 新的朋友 | 收到的朋友请求和发出的邀请（invites） |
| 添加朋友 | 创建邀请（createInvite / `create_invite`） |
| 我 | me |

## 布局

桌面（窗口宽度 ≥ 720px）分三栏，和微信一样：

| 栏 | 宽 | 背景 | 内容 |
|---|---|---|---|
| 导航栏 | 56px | `--rail` | 顶部是头像（点开是“我”），下面是消息、通讯录图标；最底部是设置菜单 |
| 列表栏 | 250px | `--list` | 顶部 60px 放搜索框和“+”，下面是列表 |
| 内容区 | 剩余宽度 | `--content` | 顶部 60px 是标题栏，下面是内容 |

- 窗口最小 720 × 520。
- 没选中任何东西时，内容区只在正中放灰色的 Achat 标志，不放文字。
- 窄屏（< 720px）一次只显示一栏，底部是标签栏（消息、通讯录、我），和手机版微信一样。
- 为以后的桌面端预留空间：Mac 的红绿灯压在导航栏顶部，所以头像上方留 28px；Windows 的最小化、关闭按钮在标题栏右侧，所以标题栏右边留 140px。导航栏、列表栏顶部和标题栏都是窗口拖动区。

## 字

字体：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif`。只用 400 和 500 两种字重，不用粗体。

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 正文、列表名字、按钮 | 14 / 20 | 400 |
| 次要文字、时间、状态 | 12 / 17 | 400 |
| 标题栏 | 16 / 22 | 500 |
| 引导页大标题 | 22 / 30 | 500 |

## 组件

- **头像**：方形，圆角 4px。导航栏 34px，列表 40px，资料页 64px。没有图片时显示 `initialOf()` 取出的那个字。
- **列表行**：高 64px，左右内边距 12px，头像和文字间距 12px。第一行是名字，第二行是 12px 灰字；时间或状态放在右侧。
- **搜索框**：高 26px，底色 `--search`，圆角 4px，左侧放大镜图标，占位文字“搜索”。右侧的“+”按钮 26 × 26，同样底色。
- **按钮**：高 32px，左右内边距 20px，圆角 4px。主按钮绿底白字，一屏最多一个；次要按钮 `--field` 底、`--ink` 字；危险按钮 `--field` 底、`--danger` 字。列表行里的小按钮（例如“接受”）高 28px，左右内边距 12px。
- **输入框**：高 32px，左右内边距 10px，底色 `--field`（直接放在内容区上时用白底），无边框，圆角 4px；聚焦时加 1px `--green` 边框。
- **弹窗**：白底，宽 380px，圆角 8px，阴影 `0 8px 32px rgba(0,0,0,.16)`，遮罩 `rgba(0,0,0,.4)`。标题 16px 放左上角，右上角是 ×；按钮放右下角，主按钮在最右。
- **菜单**：右键或点“···”时弹出。白底，圆角 4px，带阴影；每项高 32px，字号 14px；危险项用 `--danger`。
- **角标**：红底白字，高 16px，最小宽度 16px，字号 11px。只需要提醒、不需要数字时，用 8px 红点。
- **气泡**：最大宽度 60%，内边距 9px 12px，圆角 4px。自己的气泡用 `--bubble-mine`、靠右；对方的气泡白色、靠左，旁边放 34px 头像。
- **轻提示**：屏幕正中，`rgba(0,0,0,.7)` 底，白字 14px，1.5 秒后消失，例如“已复制”“已发送”。
- **图标**：线性图标，24px，描边 1.6；导航栏图标选中时变成 `--green`。
